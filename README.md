# Slice Flip

One-button 3D knife-flipping slicer, built from `Slice_Flip_Game_Design_Document.md`.

**Play:** open `index.html` in Firefox or Chrome (`xdg-open index.html`). No install or internet needed; Three.js is vendored as `three.min.js`.

**Controls:** Space / click / tap to flip · ←/→ pick level on the menu · Esc menu · M mute · `` ` `` camera debug panel (pitch, yaw, zoom).

**Test:** `node test.js` (headless physics/level self-check).
